# Linksammlung v3

Eine persönliche Linksammlung – Version 3.

## Projektbeschreibung

Dieses Projekt dient zur Verwaltung und Organisation von Links.

## Erste Schritte

```bash
# Repository klonen
git clone <repo-url>
cd Linksammlung-v3

# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev
```
